QUICK GUIDE

Welcome to WELDTECH

Use the Joint tab to move each axis. Record waypoints, then run the path to see the TCP travel and virtual weld bead.

  • Orbit: drag on the 3D view.
  • Zoom: mouse wheel / trackpad.
  • Pan: right-click drag.
  • Emergency stop: stops virtual motion and disables the arc. Reset safety before running again.

This is a simplified educational simulator. It does not predict weld quality or replace formal training, a WPS, or machine safety systems.
